About the Project

Moringa Leaf Health Diagnostic AI

The Moringa Leaf Classifier is a deep learning research project designed to accurately distinguish between healthy and diseased Moringa leaves. By leveraging state-of-the-art convolutional neural networks (CNNs), including architectures like Inception-v3 and Vision Transformers, the system achieves over 97% accuracy on validation sets.

Explainable AI (XAI) Integration

A core focus of this web application is not just providing predictions, but explaining them. The dashboard integrates Dual-XAI techniques:

  • Grad-CAM (Gradient-weighted Class Activation Mapping) highlights the exact spatial regions of the leaf that the model used to make its decision, presented as a heatmap.
  • LIME (Local Interpretable Model-agnostic Explanations) breaks the image into superpixels and masks out areas to show exactly which boundaries were most influential for the prediction.

Infrastructure

Built using Flask, TensorFlow/Keras, and beautifully designed with a "Bento 2.0" responsive architecture, this application serves as a robust prototype for agricultural disease monitoring.
